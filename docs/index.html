Multilingual Reasoning Cascades Need More Context
Multilingual Reasoning Cascades Need More Context
A Mazumder, D Zhang, SS Li, Y Tsvetkov, N Bafna - arXiv preprint arXiv:2606.27306, 2026
Translation cascades for reasoning translate the query from another language to English, reason in English, and translate the answer back to the original language. This is a competitive approach to multilingual reasoning, but structurally lossy, since each stage discards information later stages may need, including cues for cultural grounding, register, and disambiguation. We examine the benefits of a simple and training-free intervention: a context-aware translation cascade
